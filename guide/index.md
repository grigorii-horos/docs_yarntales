# Начало работы

Добро пожаловать в инструкции Yarntales! 

Это демо-страница, которая показывает, как можно организовать документацию по папкам.

## Структура сайта

- `/guide/` — здесь хранятся основные инструкции.
- `/files/` — пример организации публичных файлов с превью.

Вы можете легко добавлять новые папки и файлы Markdown (`.md`), и они будут автоматически форматироваться.
