# Публичные документы

Эта папка содержит примеры публичных файлов. 

Все эти файлы лежат физически в папке `public` и доступны для скачивания по прямым ссылкам.

### Доступные файлы:

- [📄 Скачать PDF-документ (`sample.pdf`)](/sample.pdf)
- [📊 Скачать таблицу (`data.csv`)](/data.csv)
- [🗄️ Скачать архив (`assets.zip`)](/assets.zip)

*(Вы можете нажать на ссылки, чтобы протестировать скачивание или превью в браузере).*
